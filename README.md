## Versionamento de Código

### Descrição
Este repositório contém as atividades desenvolvidas na disciplina de Técnicas de Versionamento de Código.

### Como executar o projeto
1. Clone o repositório em sua máquina:
   ```bash
    git clone https://github.com/JEANP0NTES/versionamento-de-codigo.git
    ```  
2. Acesse o diretório, via terminal:
	```bash
	cd {Localondebaixouodiretorio}/versionamento-de-codigo
	.../versionamento-de-codigo (main)
	ls -ls					# verifica os arquivos: terá o README.md
	{Agora você pode contribuir para o projeto, acrescentando/modificando}
	git remote add origin https://github.com/JEANP0NTES/versionamento-de-codigo.git
	git commit -m "Comentario significativo"
	git push -u origin main
	```
